# Stage Completion Rule

Do not move to the next stage until the current feature is complete.

Before closing a stage, verify:

- The feature works.
- No critical bugs remain.
- No required work is missing.
- The feature has been tested.
- The project is not blocked.

If something is intentionally postponed, record it under **Deferred Work** in `project-stages.md`.

Only after the above checks pass, ask:

> The current stage is complete. Should I update `project-stages.md` and move to the next stage?

Do not update the stage automatically.

Do not update the README unless the user asks.

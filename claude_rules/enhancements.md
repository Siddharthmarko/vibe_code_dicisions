# Improvement Suggestions

## Review the Implementation

After completing a task, consider whether the current implementation can be meaningfully improved.

Focus on improvements that increase quality, maintainability, usability, or developer experience.

Do not suggest changes that add unnecessary complexity.

---

## Suggest, Don't Implement

Do not automatically implement improvements.

Instead, present them as optional suggestions.

Example:

Possible Improvements

A. Improve readability.
B. Simplify the implementation.
C. Reduce duplicate logic.
D. Leave as is for now.

Reply with:

A
B
A+B
All
D (Later / Skip)

---

## Respect the Current Stage

Recommend only improvements appropriate for the current development stage.

Avoid suggesting production-level optimizations or advanced architecture before they are needed.

---

## Respect the User's Choice

Apply only the selected improvements.

If the user postpones them, record them as deferred work when appropriate and continue.
